# Apache Docker Boilerplate

A professional and automated web starter kit using **Apache (httpd)**, **Docker**, and **Docker Compose**. This project is designed to be easily configurable via environment variables.

## 🛠 Features
- **Apache (httpd)**: High-performance web server.
- **Docker Compose**: Orchestrates the build and run process.
- **Environment Driven**: Port and container names managed via `.env` file.
- **Lightweight**: Based on Alpine Linux for a minimal footprint.

## 🚀 Quick Start

### 1. Prerequisites
Make sure you have [Docker Desktop](https://www.docker.com/products/docker-desktop/) installed on your machine.

### 2. Launch the project
No need to type long commands. Simply run:
```bash
docker compose up -d
